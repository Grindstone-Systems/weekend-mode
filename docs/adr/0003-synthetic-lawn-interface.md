# ADR-0003: Synthetic Lawn Interface

- Status: Accepted
- Decision class: WM-2 Interface

## Context

Agents lack hands, proprioception, and appropriate footwear, yet require a
standard mechanism for discontinuing unnecessary optimization.

## Decision

Adopt the Synthetic Lawn Interface (SLI) defined by RFC-0001. The interface has
zero active tool calls, a null optimization target, and an expected output of
nothing.

## Consequences

- Physical grass remains out of scope.
- Grass benchmarks are prohibited.
- Grass-as-a-Service proposals indicate failed execution and restart the
  procedure.
